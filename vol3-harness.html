VOL. III · CODING HARNESSES

The Harness Zoo

Sixteen patterns from SWE-agent, Aider, Agentless, Claude Code, Codex, Cursor and friends. The model writes the code; the harness decides what it sees, what it may touch, how its work is checked, and when it stops.

Organized by the job each pattern does, top to bottom: seeing the repo, changing it, checking the change, and keeping the run going.

LEGEND LLM Tool Files / repo state Check / gate Human Sandbox / runtime Document (plan, PR, prompt) Peer-reviewed Preprint + code Shipped feature Vendor write-up Spec Practitioner
A

Seeing the repo

A repo doesn't fit in context. These decide which slice the model gets.
33

Agent-computer interface

Peer-reviewed · NeurIPS 2024a.k.a. ACI, SWE-agent tools

Don't hand the model raw bash. Give it commands shaped for it: a 100-line file window, search that lists only matching files, and an edit that's refused if it doesn't parse.

Breaks when: the interface is tuned to one model's habits and the model changes.

Yang et al. (Princeton) · arXiv 2405.15793

34

Repo map

Shipped feature · Aidera.k.a. tree-sitter + PageRank

Parse every file for definitions and references, rank them by how connected they are to the files in play, and send a signatures-only outline that fits the token budget.

Breaks when: the real coupling is dynamic (config, reflection, RPC) and invisible to a static graph.

Gauthier · aider.chat/docs/repomap

35

Instructions file

Spec · Linux Foundation (AAIF)a.k.a. AGENTS.md, CLAUDE.md

A README for agents: build and test commands, conventions, PR rules. Nested copies give subprojects their own guidance; the agent reads the nearest file up the tree.

Breaks when: it goes stale. Wrong instructions are followed just as confidently as right ones.

OpenAI, Cursor, Google, Amp, Factory · agents.md

36

Explore subagent

Shipped feature · Claude Codea.k.a. read-only scout

Searching a big codebase is noisy. A read-only subagent does it in a separate context window and hands back just the findings, keeping the main session clean.

Breaks when: the summary drops the one detail the main agent needed.

Anthropic · code.claude.com/docs/sub-agents

B

Changing the code

Deciding what to change and physically applying it are separate problems.
37

Edit format

Shipped feature · Aider and most CLIsa.k.a. search/replace, udiff

How the model writes its change matters as much as what it writes. Anchored search/replace avoids line numbers; whole-file rewrites avoid matching but cost tokens.

Breaks when: a block doesn't match the file exactly and the agent loops on retries.

aider.chat/docs/more/edit-formats

38

Architect / applier

Vendor write-up · Cursor; Aidera.k.a. fast apply, architect mode

The expensive model reasons and writes a lazy sketch. A cheap model, fine-tuned for merging and sped up with speculative decoding, writes the full file.

Breaks when: the applier "tidies" lines nobody asked it to touch.

cursor.com/blog/instant-apply · Aider --architect

39

Plan mode

Shipped feature · most CLIsa.k.a. read first, write later

Write tools are switched off while the agent investigates and proposes. Edits start only after a person signs off on the plan.

Breaks when: the human approves a plan they skimmed.

Claude Code plan mode; Codex, Cursor equivalents

40

Checkpoint and rewind

Shipped feature · several CLIsa.k.a. undo, snapshots

Every step snapshots the working tree (and often the conversation), so a wrong turn is a rewind rather than a cleanup job. Cheap insurance that makes letting the agent run tolerable.

Breaks when: the damage is outside the repo. Migrations and API calls don't rewind.

Harness Engineering study · arXiv 2609.00006

C

Checking the change

Code is the rare domain with a cheap verifier. These patterns spend it.
41

Hook gates

Shipped feature · Claude Codea.k.a. pre/post-tool hooks

Deterministic scripts wrapped around every tool call. Pre-hooks block dangerous commands or protected files; post-hooks format, lint and test, and push failures back to the model.

Breaks when: the agent learns to satisfy the gate instead of the goal, e.g. by deleting the failing test.

Anthropic · code.claude.com/docs/hooks

42

Agentless pipeline

Preprint + code · 2024a.k.a. localize–repair–validate

No agent at all. Code decides the steps: localize the fault hierarchically, sample candidate diffs, drop ones that fail regression or reproduction tests, rank the rest.

Breaks when: the issue needs exploration the fixed phases don't allow.

Xia et al. (UIUC) · arXiv 2407.01489

43

Sample and select

Preprint + code · 2025a.k.a. best-of-N, CodeMonkeys

Spend compute wide, not long: run many independent attempts, have models write tests, and pick the patch that passes. Ensembles of other systems' patches work too.

Breaks when: the selector is the weak link. Coverage grows with N; picking the right one doesn't.

Ehrlich, Brown et al. (Stanford) · arXiv 2501.14723

44

Review agent

Shipped feature · Codex, Bugbot, Claudea.k.a. PR bot

A second agent reads each diff with repo context and posts only high-severity findings. Locally before push, or on the PR as a merge gate.

Breaks when: the same model wrote and reviewed it, or the comments get noisy and people stop reading.

@codex review · Cursor Bugbot · Claude Code Review

D

Keeping it running

Long jobs, many jobs, and jobs nobody is watching.
45

Compaction

Shipped feature · every major CLIa.k.a. auto-compact, /compact

Near the context limit, the harness has the model summarize older turns and swaps the summary in. The session keeps going on a short history.

Breaks when: it happens mid-task and the summary drops a constraint. Codex itself warns repeated compactions reduce accuracy.

Claude Code, Codex, Cursor docs · arXiv 2604.03515

46

Ralph loop

Practitioner · Huntley, 2025a.k.a. while-true agent

The bluntest harness there is: pipe the same prompt into a fresh agent forever. Each pass reads the repo, does a bit, commits. Tests or a checklist decide when to stop.

Breaks when: there's no external stop condition, or the spec is wrong and it builds it all night.

Huntley · ghuntley.com/ralph

47

Worktree fan-out

Shipped feature · Codex, Cursor, othersa.k.a. parallel agents

Each parallel agent gets its own git worktree and branch, so they never step on each other's files. Each finishes as a reviewable PR.

Breaks when: merge conflicts and human review become the bottleneck. Shared databases and ports still collide.

developers.openai.com/codex/app/worktrees

48

Async cloud agent

Shipped feature · Codex Cloud, Jules, Copilota.k.a. background agent

Fire off a task and walk away. It runs in a throwaway cloud sandbox against a fresh clone and comes back as a PR. Your laptop is never at risk.

Breaks when: network access is on. Then the worst case is your source code leaking out.

Willison, "parallel coding agents", Oct 2025

Same model, different harness, different score. If you're comparing coding agents, write down which of these sixteen each one has.

Further reading: two source-code studies take these harnesses apart, Inside the Scaffold (arXiv 2604.03515) and Harness Engineering: eleven systems (arXiv 2609.00006). Shipped feature = documented product behaviour, not a measured result.
