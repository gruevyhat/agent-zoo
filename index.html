The Agent Zoo

Field guides to LLM agent architectures, drawn in the style of the old neural-network zoo posters. Each tile has a glyph, a one-line description, a failure mode, and (in Vols. II and III) an evidence grade and source.

VOL. I · PATTERNS 01–16

Recent and exotic species, 2024–2026
Recursive LMs, CaMeL, evolving playbooks, trained orchestrators, self-rewriting agents, A2A. VOL. III · PATTERNS 33–48
Coding harnesses
ACI, repo maps, edit formats, hooks, Agentless, best-of-N, compaction, Ralph loops, worktrees.
