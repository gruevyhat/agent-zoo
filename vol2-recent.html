VOL. II · RECENT AND EXOTIC SPECIES, 2024–2026

The Agent Zoo, Vol. II

Sixteen newer patterns from the last two years of papers and engineering write-ups. Three trends run through them: the scaffold becomes data (playbooks, skills, lessons), the orchestrator gets trained instead of prompted, and agents start designing agents.

Every tile carries an evidence grade. A vendor's internal eval is not a benchmark, and a protocol is not a result.

17

Recursive LM

Peer-reviewed · NeurIPS 2026a.k.a. RLM, prompt-as-variable

The long prompt never enters the context. It sits in a REPL as a variable; the model writes code to peek, slice and call itself on the pieces.

Breaks when: the decomposition code is wrong and nothing checks it.

Zhang, Kraska, Khattab · arXiv 2512.24601

18

Dual LLM / CaMeL

Preprint + code · 2025a.k.a. privileged / quarantined LLM

The trusted model fixes the control flow as code before it sees any data. Untrusted text only ever reaches a model with no tools.

Breaks when: the task needs the planner to read the data. Security is bought with utility.

Willison; Debenedetti et al. · arXiv 2503.18813

19

Evolving playbook

Peer-reviewed · ICLR 2026a.k.a. ACE, Dynamic Cheatsheet

The system prompt is treated as a living document. A reflector critiques each run and a curator adds small itemized edits instead of rewriting the whole thing.

Breaks when: the playbook grows faster than anyone audits it.

Zhang et al. · arXiv 2510.04618

20

Experience bank

Peer-reviewed · ICLR 2026a.k.a. ReasoningBank, workflow memory

After each task the agent judges its own run and distills strategies, including what not to do, into a memory it retrieves on similar tasks.

Breaks when: a self-judged "lesson" is wrong and gets applied everywhere.

Ouyang et al. (Google) · arXiv 2509.25140

21

Sleep-time agent

Preprint + code · 2025a.k.a. background consolidation

A second agent shares the first one's memory and works while the user is away: reorganizing notes and pre-computing likely answers.

Breaks when: later queries don't reuse the work. Then it's pure overhead.

Lin et al. (Letta, Berkeley) · arXiv 2504.13171

22

Skill library

Spec · open standard, Dec 2025a.k.a. Agent Skills, progressive disclosure

Procedures live in folders. The agent holds only one-line descriptions, loads a skill's instructions on a match, and opens its files only if needed.

Breaks when: descriptions are vague, so the right skill never loads.

Anthropic · agentskills.io

23

Ledger orchestrator

Preprint + code · 2024a.k.a. Magentic-One, two-loop orchestrator

The orchestrator keeps two explicit notes: a task ledger (facts, guesses, plan) and a progress ledger. An inner loop assigns work; an outer loop replans when it stalls.

Breaks when: old guesses in the ledger start being treated as facts.

Fourney et al. (Microsoft) · arXiv 2411.04468

24

Research swarm

Vendor write-up · 2025a.k.a. deep research, context isolation

Orchestrator–workers where each subagent gets a fresh context, explores one thread and hands back a compressed summary. A last pass ties claims to sources.

Breaks when: the task doesn't split into independent threads. Costs about 15× the tokens of a chat either way.

Anthropic Engineering, Jun 2025

25

Small trained conductor

Peer-reviewed · ICML 2026a.k.a. ToolOrchestra, models-as-tools

The org chart flips: a small model is trained to decide when to call search, a specialist, or an expensive frontier model, and is rewarded for cost as well as correctness.

Breaks when: you lack the RL setup, or a reward that prices cost honestly.

Su et al. (NVIDIA) · arXiv 2511.21689

26

Trained swarm

Vendor tech report · 2026a.k.a. Kimi Agent Swarm, PARL

Spawning subagents becomes an action the model learns by RL. Only the orchestrator is trained; up to a few hundred frozen workers run in parallel.

Breaks when: the fan-out is padding. Public detail is too thin to reproduce.

Moonshot AI · arXiv 2602.02276

27

Initializer + shifts

Vendor write-up · 2025a.k.a. long-running harness

Memory lives in files, not context. A first agent writes the spec and scaffolding; each later session reads the log, finishes one item, tests, commits and leaves notes.

Breaks when: the feature list is wrong on day one and every shift builds it faithfully.

Anthropic Engineering, Nov 2025

28

Evolutionary coder

Vendor report · deployed, 2025a.k.a. AlphaEvolve, FunSearch

LLMs act as mutation operators inside an evolutionary loop. Programs that score well on an automated evaluator seed the next round.

Breaks when: you can't write an automated scorer. No evaluator, no evolution.

Google DeepMind, May 2025

29

Self-rewriting agent

Peer-reviewed · ICLR 2026a.k.a. Darwin Gödel Machine

A coding agent edits its own harness. Each child is benchmarked and kept in an open-ended archive, so weaker variants survive as stepping stones.

Breaks when: the benchmark is the whole objective and gets gamed. Needs a sandbox and oversight.

Zhang, Hu, Lu, Lange, Clune · arXiv 2505.22954

30

Meta agent search

Peer-reviewed · ICLR 2025a.k.a. ADAS, AFlow

A meta agent programs whole new agent designs in code, reading an archive of earlier designs and their scores. The zoo, drawn by the animals.

Breaks when: the search eval is small, so "better" designs are noise.

Hu, Lu, Clune · arXiv 2408.08435

31

Cross-org agents

Spec · Linux Foundationa.k.a. A2A + MCP

Agents from different vendors advertise what they do in an agent card and hand each other tasks. MCP connects an agent to tools; A2A connects agents to agents.

Breaks when: you forget the other side's output is untrusted input.

Google → Linux Foundation · a2a-protocol.org

32

Human-on-the-loop

Trend claim · 2026a.k.a. supervise by exception

The successor to approval gates: agents act without asking, a person watches the stream and steps in on exceptions or alerts.

Breaks when: nobody is watching the dashboard as often as the design assumes.

Deloitte TMT Predictions 2026

Most of these are Vol. I animals with one organ upgraded: memory that learns, an orchestrator that's trained, or an evaluator that drives search.

Grades: Peer-reviewed = accepted at a major venue. Preprint + code = arXiv with released code. Vendor write-up = a lab describing its own system, usually on internal evals. Spec = a standard, not a result. Trend claim = analyst forecast.
