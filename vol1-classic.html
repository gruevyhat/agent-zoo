A FIELD GUIDE TO LLM AGENT ARCHITECTURES

The Agent Zoo

Sixteen common ways to wire models, tools, memory and people together, drawn in the style of the old neural-network zoo posters. Most real systems are two or three of these stacked.

Solid edges always fire. Dashed edges are conditional: taken by some runs, decided at run time, or used only on failure.

LEGEND Input / output LLM call Tool Memory / shared state Critic / judge / gate Human Environment / sandbox
01

Augmented LLM

a.k.a. tool-calling LLM, RAG

One model call with tools, retrieval and memory bolted on. The cell every other pattern is built from.

Breaks when: the job needs more than one step.

02

Prompt chain

a.k.a. pipeline, workflow

A fixed sequence of calls. Code decides the order, not the model; checks between steps catch bad hand-offs.

Breaks when: an input doesn't fit the script.

03

Router

a.k.a. classify-and-dispatch

One call classifies the request and sends it down a single specialist path.

Breaks when: it misroutes. The error is silent and looks like the specialist's fault.

04

Parallel / voting

a.k.a. sectioning, self-consistency

The same task, or slices of it, run as several calls at once. An aggregator merges or takes the majority.

Breaks when: the errors are correlated, so they vote together.

05

ReAct loop

a.k.a. think–act–observe, "the agent loop"

The model picks an action, reads the result and goes again until it decides it is finished.

Breaks when: it loops, drifts, or has no real notion of "done".

06

Plan-and-execute

a.k.a. planner–executor, ReWOO

A planner writes the steps up front, cheaper executors run them, and the plan is revised when a step fails.

Breaks when: the plan meets the environment and rots.

07

Evaluator–optimizer

a.k.a. Reflexion, self-refine, generate–critique

A generator drafts, a critic scores the draft and sends back notes, round after round until it passes.

Breaks when: the critic shares the generator's blind spots.

08

Orchestrator–workers

a.k.a. lead agent + subagents

A lead model decides at run time how to split the work, hands pieces to fresh workers and stitches the results.

Breaks when: context is lost in the hand-off and cost multiplies.

09

Hierarchical

a.k.a. supervisor tree, manager agents

Managers delegate to sub-managers, who delegate to workers that actually hold the tools.

Breaks when: you rebuild org-chart overhead, now billed in tokens.

10

Handoff / swarm

a.k.a. peer-to-peer agents, transfer-of-control

Peers pass control, and the conversation, to whichever agent fits the next turn. No central boss.

Breaks when: nobody owns the outcome.

11

Debate / jury

a.k.a. multi-agent debate, LLM council

Agents argue competing answers over a few rounds, and a judge picks the winner.

Breaks when: the judge rewards confidence and length.

12

Blackboard

a.k.a. shared workspace, stigmergy

Agents read and write one shared workspace. Whoever can add something next does; nobody calls anybody.

Breaks when: writes collide or state goes stale.

13

Tree search

a.k.a. Tree of Thoughts, LATS, MCTS agents

Branch several candidate next steps, score them, expand the most promising and backtrack from dead ends.

Breaks when: you don't have a scorer you trust. Also expensive.

14

Code-as-action

a.k.a. CodeAct, computer use, coding agents

A ReAct loop where the actions are code, shell commands or mouse clicks, run in a sandbox that reports back.

Breaks when: the sandbox is your only security boundary and isn't one.

15

Memory-tiered

a.k.a. MemGPT-style, long-running agent

The model pages facts between a small working context and a large archive, so one run can last days.

Breaks when: retrieval decides what it remembers, and you don't.

16

Human-in-the-loop

a.k.a. approval gate, interrupt-and-resume

A person approves side-effectful actions at defined gates: sends, payments, deletes, deploys.

Breaks when: approval fatigue turns the gate into a rubber stamp.

Start at 01. Move to a bigger animal only when you can name the failure it fixes.

Most production "agents" are 01 or 02 with a for-loop. That's fine. Say so.
